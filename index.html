SSEL · Research software · CurrentOpen CAT ↗

CAT — Communication Annotation Tool

An end-to-end platform for coding communication data in economic experiments with one or more LLMs.

My contribution
Designed and developed the full system from scratch: data ingestion, episode mapping, codebook configuration, experiment context, multi-model execution, result review, export, documentation, and deployment.
Research setting
Built at SSEL alongside our methodological work on whether LLMs can reliably code communication content in economic experiments.
Stack
Next.js, React, TypeScript, Python, FastAPI, SQLAlchemy, PostgreSQL, pandas, and openpyxl, with OpenAI, Gemini, DeepSeek, Anthropic, and xAI model integrations. Deployed on RHEL with Nginx and systemd.
